# ============================================================
# 3D 空间点标定 点对输入模板
# 复制本文件为 points_3d.txt 并填入真实数据
#
# 每行一组点:  相机X 相机Y 相机Z 机器人X 机器人Y 机器人Z
#   - 单位统一为 mm！
#     （main.py 中相机 3D 点由深度图反投影得到，单位是米，
#       程序会自动 ×1000 换算成 mm 后再应用本标定，所以这里填 mm）
#   - 相机坐标: 该点在相机坐标系下的 XYZ
#     （可用标定块角点，或把已知尺寸的物体放在视野中，
#       通过深度图读取该点的相机坐标）
#   - 机器人坐标: 机器人 TCP 触碰同一物理点时记录的基坐标 XYZ
#
# 采点方法:
#   1) 推荐 8 个以上的点，且在 XYZ 三个方向都有明显分布
#      （不能全部共面，Z 方向至少要有 2~3 个不同高度层）。
#   2) 对每个点：先让机器人 TCP 精确触碰它，记录机器人坐标；
#      再从深度图中读出该点像素对应的相机 3D 坐标。
#
# 下面的示例数据仅为演示格式，必须替换为真实数据！
# ============================================================
